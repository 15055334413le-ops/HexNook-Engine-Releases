# Hex Nook 文件引擎

为 Hex Nook Hop 等产品提供全盘文件搜索的后台服务。没有窗口，不联网，不读取文件内容。

## 下载

[下载最新版安装包 HexNookEngine-Setup.exe](https://github.com/15055334413le-ops/HexNook-Engine-Releases/releases/latest/download/HexNookEngine-Setup.exe)

一般不需要单独下载：在 Hex Nook Hop 的设置里打开「文件搜索」时会自动安装。安装需要一次管理员权限。

## 卸载

在 Windows「设置 → 应用」里找到 Hex Nook 文件引擎，点卸载。所有产品都关闭文件搜索后，它也会自动卸载。
